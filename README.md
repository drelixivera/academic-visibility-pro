# Academic Visibility Pro

A fast, responsive, single-page site for **Academic Visibility Pro** — an academic profile building consultancy helping researchers, scholars, and professionals strengthen their academic profiles for career advancement and immigration pathways (EB1A, O2, EB2 NIW).

Built with **React + Vite + Tailwind CSS v4**. No backend — all calls to action route to WhatsApp, with LinkedIn and Facebook as secondary channels.

---

## 🛠️ Tech Stack

- **Vite** — build tool
- **React 18** — UI framework
- **Tailwind CSS v4** — styling (CSS-first config via `@theme`)
- **JavaScript** — no TypeScript
- **Vercel** — hosting + CI/CD
